**Goal:** Qualify all 254 Mercury ERP catalog actions truthfully, publish secret-safe human-readable validation knowledge and accounting semantics through the existing 19-tool MCP, add host-orchestrated Cross-MCP reconciliation contracts, and release a clean public `v0.2.1` from the exact reviewed `main` commit.

**Architecture:** Keep the immutable ERP action catalog unchanged and attach version-bound qualification, semantic, and evidence sidecars keyed by `(connector_id, action_id, version_id, environment)`. FlowAccount receives reviewed sandbox attempts through the existing local credential and ERP execution boundary; PEAK receives documented-schema contract validation until UAT credentials exist. Supabase stores append-only approved validation evidence and RAG projections, while the existing local MCP composes catalog, validation, semantics, and workflow contracts without adding a second server.

**Tech Stack:** Python 3.11-3.13, Pydantic 2.13.4, httpx 0.28.1, MCP 1.26.0/FastMCP, Supabase Postgres + pgvector, pytest, Ruff, uv/uvx, GitHub Actions, Gitleaks, TruffleHog, Render.

## Global Constraints

- Preserve exactly one public plugin named `mercury-finance` and one local stdio MCP with the existing 19 tool names.
- Do not add semantic or qualification fields to `CatalogAction`; immutable action `version_id` values must not change.
- Keep ERP credentials repository-local under ignored `.mercury/` state and accept secret values only through interactive stdin.
- Never place credentials, raw provider payloads, provider record IDs, tax IDs, emails, local paths, or audit traffic in Git, Supabase knowledge, Render logs, release artifacts, MCP public output, or deterministic summaries.
- FlowAccount live calls are sandbox-only, HTTPS-only, no redirects, no embedded credentials, no unexpected ports, and must reject production hosts before authentication.
- A live mutation requires an exact reviewed action-version manifest entry, fixture ownership predicate, approved fixture builder, bounded request budget, cleanup method, and explicit sandbox approval.
- Email, share, invite, payment, delete, void, and uncontrolled external effects remain blocked unless the reviewed manifest proves sandbox confinement and a controlled destination.
- Never retry an `outcome_unknown` mutation; cleanup failure or unknown outcome quarantines the run and blocks public promotion.
- PEAK `contract_validated` means frozen-catalog and documented-schema conformance only; it must never be presented as a successful provider/UAT call.
- Public evidence is append-only, selected by exact action version and environment, and cannot let an older success hide a newer failed or quarantined run.
- Cross-MCP content is untrusted data. Mercury returns typed plans and handoffs; the host agent invokes Drive, Sheets, Gmail, or other MCP servers with separate approvals.
- Public release is fail-closed: required scanner, migration, MCP, live-sandbox, clean-install, artifact, staging, Render, or hosted-surface failures block tagging or visibility changes.
- `v0.2.1` is an immutable annotated tag created once on the exact reviewed remote `main` commit; discrepancies require a new version, never a moved tag.
- The primary GitHub repository remains private until every pre-public gate passes.
- Public copy must state: `Mercury Tools is an independent open-source project and is not affiliated with Mercury Technologies, Inc.`

```python
MAX_DEPTH = 6
MAX_FIELDS = 128


def extract_response_shape(value: Any, *, depth: int = 0) -> dict[str, Any] | str:
    if depth >= MAX_DEPTH:
        return "truncated"
    if isinstance(value, Mapping):
        keys = sorted(str(key) for key in value)[:MAX_FIELDS]
        return {key: extract_response_shape(value[key], depth=depth + 1) for key in keys}
    if isinstance(value, list):
        return {
            "type": "array",
            "items": extract_response_shape(value[0], depth=depth + 1) if value else "unknown",
        }
    if value is None:
        return "null"
    if isinstance(value, bool):
        return "boolean"
    if isinstance(value, int):
        return "integer"
    if isinstance(value, float):
        return "number"
    return "string"
```

```python
def load_semantic_contracts(
    path: Path,
    actions: Sequence[CatalogAction],
) -> dict[tuple[str, str], SemanticContract]:
    payload = json.loads(path.read_text(encoding="utf-8"))
    rows = payload.get("contracts")
    if not isinstance(rows, list):
        raise ValueError("semantic_contracts_invalid")
    expected = {(item.action_id, item.version_id) for item in actions}
    result: dict[tuple[str, str], SemanticContract] = {}
    for row in rows:
        action_id = row.pop("action_id")
        version_id = row.pop("version_id")
        key = (action_id, version_id)
        if key in result or key not in expected:
            raise ValueError("semantic_contract_identity_invalid")
        result[key] = SemanticContract.model_validate(row)
    if set(result) != expected:
        raise ValueError("semantic_contract_coverage_incomplete")
    return result
```

- [ ] **Step 4: Add recursive forbidden-key validation to the migration**

Add `public.jsonb_has_forbidden_validation_key(value jsonb)` and a table check that rejects these normalized key fragments anywhere in public JSON: `authorization`, `token`, `secret`, `password`, `api_key`, `client_id`, `client_secret`, `email`, `tax_id`, `path`, `uri`, `raw`, `payload`, and `response`. Do not reject semantic field names such as `document_id` or `record_id`; typed publication removes their values while response-shape and semantic contracts may retain those field names.

```sql
create or replace function public.jsonb_has_forbidden_validation_key(value jsonb)
returns boolean
language sql
immutable
set search_path = public, pg_temp
as $$
  select exists (
    select 1
    from jsonb_path_query(value, 'strict $.**.keyvalue()') as item
    where lower(regexp_replace(item->>'key', '[^a-zA-Z0-9]+', '_', 'g')) = any(array[
      'authorization', 'token', 'secret', 'password', 'api_key', 'client_id',
      'client_secret', 'email', 'tax_id', 'path', 'uri', 'raw', 'payload', 'response'
    ])
  );
$$;
```

```python
class EvidenceRequest(StrictSafeModel):
    connector_id: str
    action_id: str
    version_id: str
    environment: str

    def matches(self, record: ValidationKnowledge) -> bool:
        return (
            self.connector_id,
            self.action_id,
            self.version_id,
            self.environment,
        ) == (
            record.connector_id,
            record.action_id,
            record.version_id,
            record.environment,
        )


class EvidenceSelection(StrictSafeModel):
    selected: ValidationKnowledge | None
    blocking_conditions: tuple[str, ...]
    records: tuple[ValidationKnowledge, ...]


def select_evidence(
    records: Sequence[ValidationKnowledge],
    *,
    request: EvidenceRequest,
    now: datetime,
) -> EvidenceSelection:
    scoped = [record for record in records if request.matches(record)]
    if len(scoped) != len(records):
        raise ValueError("evidence_scope_mismatch")
    current = [
        record for record in scoped
        if record.approved_public and (record.expires_at is None or record.expires_at > now)
    ]
    current.sort(key=lambda item: item.evaluated_at, reverse=True)
    blockers = tuple(
        dict.fromkeys(
            record.validation_status.value
            for record in current
            if record.run_state is QualificationRunState.QUARANTINED
            or record.validation_status in BLOCKING
        )
    )
    selected = None if blockers else next(
        (record for record in current if record.validation_status is ValidationStatus.LIVE_SUCCESS),
        next((record for record in current if record.validation_status is ValidationStatus.CONTRACT_VALIDATED), None),
    )
    return EvidenceSelection(selected=selected, blocking_conditions=blockers, records=tuple(current))
```

```python
    return CleanupReport(

        failed_handles=tuple(failures),
```
