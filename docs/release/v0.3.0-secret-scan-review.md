# v0.3.0 Secret Scan Review

Review date: 2026-07-21

This record contains only sanitized classification results. Raw detector output
and matched values were not written to Git, logs, or release artifacts.

## Archive scanner correction

- Hosted archives are scanned in two independent passes: the complete staging
  directory containing the raw archive and the isolated decoded archive tree.
- Decoded findings are compared with the allowlist using their source-relative
  member paths instead of the scanner wrapper path `decoded/`.
- TruffleHog raw-container findings are deduplicated only when a decoded member
  has the same location-independent detector and matched-value identity.
- Gitleaks remains bound to exact file, rule, line, and the SHA-256 digest of
  the actual matched value; it does not use identity-based reconciliation.
- Unredacted Gitleaks reports exist only inside a private temporary directory
  during inspection and are deleted without entering Git, logs, or artifacts.
- A finding present only in the raw container remains blocking.

## Reviewed fixture fingerprints

Eight additional exact fingerprints were classified as `non_secret_fixture`:

- Synthetic inbound-redaction values in `tests/test_cloud_api.py`.
- Synthetic API-key, AWS-token, and JWT redaction values in
  `tests/test_cloud_secret_removal.py`.
- Synthetic package-validation credential values in
  `tests/test_plugin_package.py`.
- One unverified URI detector result from the isolated Git test helper in
  `tests/test_release_secret_scanner.py`.

Every entry is bound to an exact file, scanner evidence digest, reviewer role,
and expiry. No directory-wide, detector-wide, repository-wide, or wildcard
exception was added. The reviewed entries expire on 2026-08-15.

## Git history reconciliation

The full-history CI gate identified 12 additional unique fingerprints from
older revisions of existing test fixtures and one documentation placeholder.
Each result was reclassified from sanitized metadata only: test findings use
`example.test`, `example.invalid`, or an explicit test-only value, and the
documentation result is the previously reviewed FlowAccount placeholder.

These history-only fingerprints are independently bound to their exact file
and scanner evidence digest. They do not allow a matching detector in another
file, on another line identity, or with another matched value. The resulting
35-entry allowlist is the exact union required by the current release archive
and the repository history gate.

## Verification

The final `mercury-tools-v0.3.0.tar` release candidate passed ten consecutive
scans with Gitleaks 8.24.3 and TruffleHog 3.88.32 before the history-only union
was added. The independent decoded pass and identity-safe TruffleHog
reconciliation accepted the reviewed archive without exposing raw matched
values. A final archive recheck and full-history CI gate verify the 35-entry
exact allowlist; raw-only synthetic findings remain covered by a regression
test and continue to block release.

## Attestation relay log remediation

On 2026-07-23, the hosted-surface gate found one unverified TruffleHog `Box`
detector result in the failed v0.3.0 release run `30029204578`, job
`89286203352`. Sanitized review identified the source field as
`ATTESTATION_GZIP_B64`: a compressed, sanitized release attestation transported
through a workflow-dispatch input. The detector fingerprint was
`b57c3572b765ce068860bed7fdb932ca1fa3da01b448db15db333e8680fa04d3`;
the matched value was not written to this repository or the review record.

The release consumer now streams that input from the runner-owned
`GITHUB_EVENT_PATH` directly into the bounded relay decoder. It no longer
places the transport value in a step environment, where GitHub would render it
in the job log. Regression tests require the input to remain absent from the
decode-step environment and from workflow expression interpolation.

No allowlist exception was added for this result. The failed workflow run was
removed after this sanitized evidence was recorded because GitHub does not
support redacting one value from an existing Actions log. The run produced no
release and its temporary artifacts had already been removed.
