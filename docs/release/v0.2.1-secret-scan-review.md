# v0.2.1 Secret Scan Review

Review date: 2026-07-15

This review records the false-positive classification used by the v0.2.1
release gates. It does not contain raw detector output or credential values.

## Result

- Gitleaks 8.24.3 scanned the complete repository history. Fifteen findings were traced to
  synthetic redaction and scanner tests. `.gitleaks.toml` permits only the
  reviewed rule, exact file, and exact line shape combinations.
- TruffleHog 3.88.32 runs serially with network verification disabled and
  found 20 URI occurrences represented by 17 unique fingerprints. Every occurrence is a
  rejection test or documentation placeholder under a reserved example
  domain.
- No path-wide, commit-wide, detector-wide, or repository-wide exclusion is
  used.
- The reviewed TruffleHog fingerprints expire on 2026-08-15. They bind the
  detector, decoder, verification state, file, line, and raw-value digest. Git
  commit attribution is excluded because TruffleHog can reassign identical
  evidence across synthetic merge refs. Serial execution also prevents decoder
  ordering from changing RawV2 attribution. Any other changed field or new
  finding blocks the gate.

## Reviewed Surfaces

- Public endpoint validation plan examples
- Catalog model and importer rejection tests
- Catalog sanitization tests
- FlowAccount sandbox URL guard tests
- Generic connector driver URL validation tests
- Release scanner URL validation tests

The raw JSONL report is created with owner-only permissions in the CI runner's
temporary directory, consumed by `scripts/verify_trufflehog_report.py`, and
deleted before the step exits.
