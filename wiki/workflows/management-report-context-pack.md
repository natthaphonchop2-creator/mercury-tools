# Management Report Context Pack

รายงานผู้บริหารควรสรุปรายได้ ต้นทุน กำไรขั้นต้น กระแสเงินสด ลูกหนี้ เจ้าหนี้
สต็อกสินค้า ค่าขนส่ง ต้นทุนวัตถุดิบ และรายการผิดปกติ โดยต้องแยกข้อมูลที่ดึงได้
จากระบบบัญชีออกจากข้อมูลที่ยังไม่ได้เชื่อมต่อ เช่น TikTok Shop, Shopee,
คลังสินค้า หรือระบบขนส่ง

A management report context pack should include revenue, cost, gross margin,
cash-flow indicators, anomalies, missing data, and accountant review points.

If marketplace orders, shipping cost, raw material cost, or inventory movement
data are not connected, Mercury must state those missing data sources instead of
estimating profit from invoices alone.
